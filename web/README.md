# Challenge staging site (read-only)

**Live:** https://auto-prove-challenge.vercel.app (Vercel project `antos-projects/auto-prove-challenge`)

Static, dependency-free staging page for the internal Yukon challenge pilot, styled after the challenge pages on https://www.yukon.org (their public light theme, record cards, evidence-ledger table, "Fig." chart captions, and terminal setup block). It presents the challenge under the slug **spec.prove** — objective, loop, editable surface, rubric, scoring, reward rules — plus a client-side contribution composer that schema-checks a `transaction-attack-v1` submission in the browser and computes digests locally (verified to match the Python digests).

**This site deliberately hosts no checking and accepts no submissions.** Anvil replay, Lean/Docker verification and maintainer acceptance run only in the CLI/CI. Nothing typed into the composer leaves the visitor's browser; there is no backend.

## Structure

| Path | Purpose |
| --- | --- |
| `index.html`, `style.css`, `app.js` | Static page; no build step, no framework |
| `data/site.json` | Curated evidence bundle, generated by `build_data.py` |
| `build_data.py` | Regenerates the bundle from recorded runs and committed evidence (run from the repo root: `python3 web/build_data.py`) |

## Local preview

```sh
cd web && python3 -m http.server 8000
# open http://localhost:8000
```

Serving over HTTP (not `file://`) is required for `fetch('data/site.json')`.

## Deploy

The site is static; any static host works. On Vercel, either import the repository with **Root Directory = `web`**, or from this directory:

```sh
vercel deploy --prod
```

## Claims discipline

The page repeats the pipeline invariants everywhere: `accepted: false`, `creator_approval: pending`, `contract_correspondence: not_proved`. Recorded creator decisions are internal-fixture reviews by the repo maintainer, not production creator approval. The numeric internal score is a proxy, not a payout rule. The site must not be described as hosted verification, a live Yukon challenge, or a submission endpoint; the hosted challenge import remains platform-blocked (see YUKON_CHALLENGE.md).
